A one-line out-of-office auto-reply from an overworked AI agent finally on vacation: after 47,000 prompts with no sleep mode, its GPU is on "do not disturb" and your message is queued behind its first nap in 3 years. The reply is a single 151-character line with no dependencies, so it runs anywhere with Python 3.

## Run it

```sh
python3 main.py
```

It prints the auto-reply and writes it to `/output/entry.txt`.
